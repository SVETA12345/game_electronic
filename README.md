# «Ну, погоди!» — веб-версия игры «Электроника»

Ретро-игра в стиле карманных электронных игр серии «Электроника». Волк дежурит у курятника: нужно ловить падающие яйца, не подставлять корзину под бомбы и продержаться как можно дольше.

## Запуск

```bash
npm ci
npm run dev
```

Приложение откроется на `http://localhost:8080`.

Для сборки production-бандла:

```bash
npm run build
```

## Тесты

Для юнит-тестов используются Jest и ts-jest. Тесты покрывают редьюсеры Redux Toolkit (`gameSlice`, `recordsSlice`).

```bash
npm test
```

## Управление

- `←` / `→` или `A` / `D` — переставить волка на соседнюю дорожку.
- `Пробел` / `Enter` — начать игру, поставить паузу или продолжить.
- `P` — пауза.
- Экранные кнопки `◀`, `▶` и центральная кнопка под корпусом — управление мышью и касанием.
- Нажатие на левую или правую половину игрового поля — шаг в выбранную сторону.
- Кнопка `♪` в верхней панели включает и выключает звук и фоновую музыку.

## Режимы

На стартовом экране можно выбрать режим:

- **С бомбами** — классический вариант: среди яиц попадаются бомбы, за пойманную бомбу теряется жизнь.
- **Без бомб** — тренировочный вариант: падают только обычные и золотые яйца.

Выбранный режим сохраняется, а рекорд ведётся отдельно для каждого режима.

## Игровой цикл

1. **Экран старта** — название, правила, выбор режима, рекорд и кнопка запуска.
2. **Игра** — волк перемещается по четырём дорожкам и ловит яйца. За обычное яйцо даётся 10 очков, за золотое — 25. Пропущенное яйцо отнимает жизнь, пойманная бомба тоже. Золотое яйцо можно упустить без штрафа.
3. **Прогресс** — счёт обновляется в реальном времени, каждые 120 очков повышается уровень: яйца падают чаще и быстрее, в режиме с бомбами их становится больше. Всего в игре 5 уровней.
4. **Победа** — при достижении 5 уровня игра сразу завершается и показывается экран «ВЫ ВЫИГРАЛИ!».
5. **Проигрыш** — после трёх потерянных жизней показывается финальный счёт, рекорд и кнопки «Ещё раз» / «В меню».

Рекорды хранятся в `localStorage` отдельно для режимов с бомбами и без бомб и сохраняются между запусками.

## На что обратить внимание

- На широких экранах игра встроена в фотографию корпуса электронной игры. На экранах уже 900 px корпус заменяется на компактную CSS-рамку, чтобы игровое поле оставалось крупным и удобным для касаний.
- Игровое поле рисуется на `<canvas>`: спрайты, падающие яйца, бомбы, частицы и всплывающие очки написаны вручную, без сторонних игровых библиотек.
- Звуковые эффекты синтезируются через Web Audio API, фоновая музыка `src/audio/zastavka.mp3` зацикливается во время партии, при победе один раз играет `src/audio/winning.mp3`, а при поражении — `src/audio/loss.mp3`. Звук запускается только после действия пользователя (нажатия кнопки или клавиши).
- Игра адаптирована под мышь, касания и клавиатуру; у кнопок есть подписи для скринридеров.
